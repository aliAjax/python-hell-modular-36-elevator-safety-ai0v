井道占用账常用接口

GET  /api/shafts/<id>/account
POST /api/work_permits            # 申请进场许可
POST /api/entities/<id>/actions   # issue/activate/confirm_evacuation/close
POST /api/offline-records          # 断网记录按 source_id+shift_id+seq 合并
GET  /api/offline-shifts           # 漏传/重复/冲突核对
POST /api/operations               # create/transition/batch 持久化操作
POST /api/operations/<id>/retry    # 保留已确认步骤，重试未完成项
